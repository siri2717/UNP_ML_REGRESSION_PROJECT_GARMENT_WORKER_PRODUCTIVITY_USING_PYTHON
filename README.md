# UNP_ML_REGRESSION_PROJECT_GARMENT_WORKER_PRODUCTIVITY_USING_PYTHON

This project was completed as part of the **United Network of Professionals (UNP) Machine Learning Academic Internship Program**.

The project focuses on predicting garment workers' productivity using machine learning and statistical analysis. It aims to understand how workplace conditions, operational factors, and employee-related variables influence productivity in the garment manufacturing industry.

### Project Overview
- Analyzed a dataset containing 1,197 records and 15 attributes related to garment production.
- Conducted exploratory data analysis (EDA) to identify patterns, trends, and relationships affecting worker productivity.
- Investigated productivity variations across departments, teams, quarters, and working days.
- Performed data cleaning, missing-value analysis, and categorical data preprocessing.
- Applied feature engineering and correlation analysis to identify relevant predictors.

### Machine Learning Implementation
- Developed regression models using Linear Regression, K-Nearest Neighbors, and Support Vector Regression.
- Implemented Decision Tree, Random Forest, and XGBoost regression algorithms.
- Explored Artificial Neural Networks (ANN) using TensorFlow for productivity prediction.
- Used Variance Inflation Factor (VIF) analysis to identify multicollinearity among features.
- Compared different regression algorithms across multiple training and testing configurations.
- Applied cross-validation and hyperparameter tuning to evaluate model performance.

### Model Evaluation
- Assessed predictive performance using regression evaluation metrics.
- Compared model performance to understand the effectiveness of different algorithms.
- Analyzed the relationships between operational factors and actual worker productivity.

### Project Outcome
The project provided hands-on experience in exploratory data analysis, statistical techniques, feature engineering, regression modeling, and neural networks. It demonstrates how machine learning can be applied to manufacturing datasets to investigate productivity patterns and support data-driven operational analysis.
